# Heart Disease Risk Predictor 🫀

Interactive web app that predicts cardiovascular disease risk using Machine Learning.

## 🌐 Live Demo
👉 [Try the app here](https://heart-disease-predictor-app1.streamlit.app/)

## Features
- Real-time heart disease risk prediction
- Interactive clinical data input
- SVM model trained on Cleveland Heart Disease Dataset
- 88% accuracy, AUC = 0.953

## Technologies
- Python, Streamlit
- Scikit-learn, Pandas, NumPy

## Conclusion
This web application demonstrates how Machine Learning models can be deployed as clinical decision support tools. Built with Streamlit and powered by an SVM model achieving 88% accuracy, it allows healthcare professionals to assess cardiovascular risk in real time — bridging the gap between AI research and clinical practice.

## Data Source
Cleveland Heart Disease Dataset - UCI Machine Learning Repository
